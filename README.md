# Finscope

此应用工程面向 **Android**。当前版本采用设备本地模式：用户自行导入的 Finnhub API Key 会保存在系统安全存储中；自选、虚拟账户、持仓、交易流水和资产快照保存在当前设备的本地存储中。应用不要求登录，不提供跨设备同步，也不托管用户 API Key。

## 用途

适用于：
1. 已确定想买的股票，但不敢入手，需要先尝试一下看看行情。
2. 想戒炒股，但是深陷其中，暂时无法戒掉。
3. 纯装逼，我要鹤立鸡群！

## 启动

在 `mobile/` 目录执行：

```bash
npm install
npm run start
```

随后使用 Expo 的 Android 启动方式，或在开发期间执行 `npm run web` 查看跨端预览。进入“设置”页面，粘贴个人 Finnhub API Key；密钥会先以真实报价校验，再保存至系统安全存储。设置页只显示掩码与最后四位，不提供完整密钥回显。

## 数据与风险边界

行情、日线、公司资料和新闻均通过 Finnhub 公共数据接口请求，并在界面显示供应商与刷新时间。模拟账户起始虚拟现金为 100,000 美元；所有买卖仅影响当前设备中的纸面账户，不会连接券商、交易所或支付渠道。

> **信息仅供学习研究，不构成投资建议。虚拟资金，非真实交易。**

## 本地数据清理

应用内可移除 API Key 和重置虚拟账户。卸载应用或清除应用数据也会清除普通本地数据；不同操作系统对安全存储的卸载后行为可能不同，敏感凭证应以应用内“移除设备中的 API Key”作为常规清理方式。
