# Finscope Android WebView 内测 APK

这是已获用户授权的 **Android 内测 WebView 壳**。它将 `mobile/` 导出的跨端界面离线封装进 APK；当前默认使用**无需注册的公开行情测试源**，覆盖已实测的国内指数、A 股、港股报价、日线与部分标的分时。Tushare Pro 与 Finnhub 仍可由用户在设置页输入自己的凭证后选择使用。

> 默认公开行情源仅基于实测公开延时响应，没有面向第三方的字段契约、服务等级保证或商业展示授权。它不是正式 API，也不应作为生产或交易决策数据源。行情与图表仅供学习研究，不构成投资建议。

## 本次版本内容

分时页会在当前公开测试源返回有效分钟数据时绘制真实价格曲线和成交量，并标注“今日分时 · 默认定位最新时点”。日 K、周 K 与月 K 都会在发生横向溢出时自动定位到最右侧的最新数据；无分时或无日线时会显示明确状态，而不以空白图表伪装数据。

分时与日/周/月 K 线支持在图表上长按或滑动以显示十字光标。分时详情显示该分钟的时间、价格、相对前点涨跌、成交量和成交额；K 线详情显示相应交易时点的开高低收、涨跌和成交量。两个图表同时显示供应商报价更新时间，国内时点按中国市场时区展示。

图表采用两阶段手势：**普通横向滑动**仍浏览时间轴；静止按住约 180ms 后进入十字光标模式。Android 壳会把原生 `down`、`move`、`up`/`cancel` 触控坐标直接派发给页面图表，因此即使 WebView 的横向滚动接管部分原始事件，十字光标仍能持续更新；图表保持长按开始时的横向偏移。松手或手势被系统打断时立即移除十字线和详情面板。本版同时恢复 K 线 **MA5（黄）/MA10（橙）/MA20（蓝）**三条均线与图例。Finnhub 适配器按官方 Candle 文档请求 `resolution=1` 分时与 `resolution=D` 日线；仅在用户 Key、标的和套餐实际支持时绘制。若遇到 `no_data`、401/403、429 或非 `ok` 响应，图表会显示权限、覆盖、休市或限流原因，避免静默空白。[Finnhub Candle 文档](https://finnhub.io/docs/api/stock-candles)

当前受控验收凭证对 `AAPL` 的 `resolution=1` 和 `resolution=D` 均返回 HTTP 403，说明该凭证没有 Candle 数据授权；这与 Finnhub 将 OHLCV Candle 标为 Premium 的公开说明一致。该情况不是 UI 渲染故障。只有你的 Finnhub 套餐已获 Candle 权限时，应用才会显示实际分时和K线。

本地账户会为每个持仓保存最近一次有效报价标记。切换数据源后，若新源未覆盖该持仓或暂时没有报价，累计盈亏、持仓市值和资产曲线会继续使用最近标记，而不会归零；“当日盈亏”在没有当前源的昨收/现价对时显示 `—`，避免将未知数据误显示为零。数据源切换采用独立请求会话，旧源的异步分时、日线和研究请求不能再覆盖新源；页面导航改为短淡出、170ms 淡入与轻微位移回正，避免硬切。

已核查腾讯证券与腾讯云公开文档范围，未发现可供第三方 App 合规接入的腾讯个股资讯 API。因此，默认国内公开行情测试源不展示或复用腾讯财经网页资讯；国内标的会明确提示当前未接入授权资讯服务。Finnhub 资讯仍仅在用户个人 Key 的实际授权范围内适用于其覆盖标的。

启动链路采用三层深色底板：Android 主题窗口背景、原生 WebView 加载遮罩以及离线 `index.html` 的黑色启动壳。页面完成后原生壳以约 **180ms** 的透明度过渡展示，应用内部首屏和切页也使用短暂、克制的淡入效果。静态封装脚本会将 Expo 的 `_expo` 目录改为 Android 可打包的 `expo`，并迁移 pnpm 隐藏路径下的图标字体，避免由资源丢失导致的白屏。

> 在该 WebView 内测壳中，用户输入的 Tushare Token、Finnhub Key、自选和本地账户数据使用 WebView 本地存储，不使用 Android SecureStore。请勿输入生产凭证。所有买卖仅影响本设备的本地账户，不会向券商、交易所或第三方下单。

## 构建

在已安装 Node.js、JDK 21、Android SDK（API 36）和 Gradle 8.10.2 的环境中，进入本目录后执行：

```bash
bash scripts/stage-web-assets.sh
/home/ubuntu/gradle-8.10.2/bin/gradle :app:assembleDebug --no-daemon --max-workers=1
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 安装与复测

该 APK 可覆盖同包名且同为调试签名的较早 `versionCode 5` 至 `versionCode 15` 测试包。可以将 APK 传到设备后用文件管理器打开，并仅向该安装来源授予“安装未知应用”权限；也可以在启用 USB 调试后执行 `adb install -r app/build/outputs/apk/debug/app-debug.apk`。若设备中的同包名 APK 使用不同签名，需先卸载旧包。

安装后请确认启动窗口始终保持深色、首次风险确认可见、默认自选可以载入公开延时行情；选择贵州茅台等已有分钟响应的标的后，检查分时图的价格区间与页面报价一致且默认显示当日最新一端。再切换日 K、周 K、月 K，确认横向可滚动周期默认展示最新交易数据。最后可在设置页检查完整风险提示，并在交易页验证本地账户操作不涉及真实订单。
