# 腾讯公开个股资讯接口核查

## 结论

截至 2026-08-27，未检索到腾讯面向第三方开发者发布、且具有明确授权条款、字段契约、调用方式和服务边界的**个股资讯 API**。腾讯证券行情中心官网可以作为终端页面浏览行情、市场栏目和文章内容；其公开页面本身并不构成第三方在 App 中批量获取、再展示文章或复用底层请求的 API 授权。[1]

腾讯云开发者社区的“腾讯股票 API”检索页收录的是社区文章和第三方服务介绍，而非腾讯财经面向开发者的产品文档；该页面不能作为接入腾讯财经资讯数据的授权依据。[2] 对腾讯云与开放平台文档范围的复核也没有发现可供本项目使用的股票资讯产品 API。[3]

因此，Finscope 将**停止**在默认腾讯公开行情测试源上实现国内个股资讯列表，不会继续探测、抓取、逆向或复用腾讯财经网页的内部网络路由、页面源码或文章数据。默认国内标的在图表下只会显示“当前未接入授权资讯服务”的明确状态。未来如获得腾讯正式数据授权包，或用户提供具备明确授权的国内资讯供应商凭证，可再按该供应商的官方文档进行单独接入。

## 已保留的可选路径

| 路径 | 适用范围 | 当前处理 |
| --- | --- | --- |
| Finnhub `company-news` | 以用户个人 Key 实际可访问的海外标的为准 | 已有 provider 能力；仅在返回数据时展示。 |
| 具备新闻权限的 Tushare 或企业数据服务 | 由用户签约范围与权限决定 | 暂不假定可用，等待用户提供授权凭证与官方接入文档。 |
| 默认腾讯公开行情测试源 | 国内指数、A/H 股的已实测报价、日线与部分分钟数据 | 不提供国内个股资讯，且保持“延时、未文档化、仅内测”提示。 |
