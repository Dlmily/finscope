# 验证记录

## Expo Web 预览

已在 Expo Web 预览中检查以下界面：

- 自选页在未配置密钥时展示“未连接数据密钥”，不会展示硬编码价格，并明确说明不会抓取或复用参考小程序内部接口。
- 设置页展示 Finnhub 为当前已实现的数据适配器、个人 API Key 输入框、安全保存并校验操作，以及 iOS/Android 与 HarmonyOS NEXT 的兼容边界。
- 全局界面采用黑色终端背景、青色/洋红色信号色、等宽式系统标签和固定底部导航，符合系统故障视觉方向。

当前 Web 预览仅用于开发校验；iOS 与 Android 版本仍需在原生设备或模拟器中安装验证系统安全存储、网络权限和布局。

## 设置页密钥保护复核

Expo Web 预览中的设置页已验证：Finnhub API Key 输入框以密码类型呈现，没有眼睛图标或其他完整明文查看入口；页面只提示密钥会保存在设备安全存储中，完整密钥不会回显或上传。实际已保存密钥时，界面仅显示掩码和最后四位。

## 风险提示复核

模拟交易页在资产摘要和委托区之前显示“虚拟资金，非真实交易”，并明确不会向券商、交易所或第三方下单。企业研究页在顶部显示“信息仅供学习研究，不构成投资建议”，且在未选标的时引导用户先从行情页载入真实资料；两项提示在 Web 预览中均清晰可见。

## Android WebView 离线启动修复

首个 WebView 测试 APK 白屏的原因是 Expo 静态导出将 JavaScript 放在 `_expo` 目录，而 Android 资源打包器未将该下划线开头目录纳入 APK。封装脚本现将目录重命名为 `expo`，并将 `index.html` 的脚本入口改为相对路径 `./expo/...`。修复后的 APK 已确认内嵌 JavaScript，且使用 Chromium 以 `file://` 协议加载同一离线入口时成功显示“未连接数据密钥”首屏，控制台没有输出错误。仍需由用户在 Android 真机侧载新版 APK 后复测触控、网络和本地存储行为。
