# 参考站公开授权边界复核

> 复核日期：2026-08-26。范围仅限公开网页和公开隐私指引；未使用开发者工具提取接口、未下载或分析前端源码、未请求隐藏路由。

| 公开材料 | 可确认内容 | 不能据此推导的权限 |
| --- | --- | --- |
| [FinScope AI 公开市场页](https://finance.baidu.com/) | 页面公开展示市场、排行、资讯和行情内容。 | 无法据此推导第三方可复制行情、资讯、榜单或其数据更新链路。 |
| [百度股市通隐私政策](https://gushitong.baidu.com/gstapi/baseInfo/ysxy) | 政策描述用户可通过网页端、移动端、SDK、API 等方式访问该产品服务；也描述其对用户个人信息的处理。 | 该隐私政策不是面向第三方的行情数据再分发许可、API 开发者文档或商业数据授权协议。 |

## 结论

可在浏览器开发者工具中观察到网络请求，只能说明浏览器客户端为使用该产品而发起请求；它不构成将请求、参数、签名、代理地址、响应内容或前端源码复制到另一款产品中的授权。当前公开材料也没有提供可供本项目使用的第三方行情数据 API 合约。

因此，Finscope 测试 App 不接入参考站的未公开路由、不抓取页面数据、不逆向签名或客户端逻辑，也不复用其数据内容。若业务方确实拥有授权，应由该服务的业务/法务/安全负责人提供书面授权、开发者 API 文档、测试凭据、配额与数据再展示范围；在此基础上可将其作为一个具名、可审计的可选 provider 接入。

当前免注册测试包采用的是独立的公开延时行情适配器，界面明确标示来源与延时属性；该适配器同样不应被视为生产级数据授权。生产环境应使用经过合同/书面授权的数据供应商。

## 可实施的数据接入路径

| 路径 | 可覆盖范围 | 必要条件 | 适用结论 |
| --- | --- | --- | --- |
| 参考站所属团队提供的正式 API | 以书面契约和接口范围为准，可包含其已获授权的国内行情、资讯或研究字段。 | 业务负责人或数据权利方提供授权说明、开发者文档、测试凭据、数据展示/再分发范围、调用配额及安全要求。 | 若用户所在团队可取得该材料，这是最直接的接入方式。 |
| 正式市场数据供应商或交易所授权链路 | 由供应商合约界定，可覆盖实时/延时行情、历史 K 线、基本面和资讯。 | 签订适当的展示或再分发许可；生产环境在服务端保管凭据，执行审计与限流。 | 面向公开发布和长期稳定性时应选此路径。上证所信息网络公开列示 Level-1/Level-2 市场数据产品。 |
| 用户个人 Token 的研究型数据服务 | 取决于 Token 权限；例如 Tushare 文档列示了沪深/北交所/港交所代码与日线、分钟、财务数据。 | 用户自行申请并在设备端导入；必须显示权限不足和延时/覆盖范围。 | 适合作为个人研究功能，不可默认视为产品再分发授权。 |
| 公开延时页面或未文档化 HTTP 端点 | 可能提供演示性的延时价格和日线。 | 无法凭“可访问”推定许可、稳定性或 SLA。 | 仅可作为内测体验演示，不用于生产数据承诺。 |

## 需要的最小授权包

如果可由参考站所属团队提供正式接入，应至少包含：数据字段清单及市场范围、允许展示与是否允许二次分发、刷新频率/延时规则、请求认证方式、测试与生产环境地址、调用配额、错误码、数据纠错责任、日志审计要求、终止与下线机制。获得这些材料后，可在不改变当前可插拔 provider 架构的前提下，新增一个具名的受授权 provider。
