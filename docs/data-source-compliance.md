# 数据源合规评估

参考页面公开展示为百度智能小程序的“Finscope/百度股市通”入口。页面元数据及运行配置仅表明其具有自选、行情、资讯、交易等信息架构，并未公开可供第三方复用的授权行情接口；运行配置还列出了多项受限宿主能力与第三方网页白名单，不能视为数据再分发授权。

百度智能小程序运营规范要求开发者遵守平台服务协议和规则，强调不得未经授权使用他人版权内容、不得滥用平台接口或能力。基于这一点，本 App **不会抓取、逆向或重放**该小程序的内部请求，也不会将其页面内容作为生产行情或资讯源。

本项目将保留可切换的数据源适配层：当前使用服务端 Finnhub 适配器；用户可在 App 中自行导入个人 Finnhub API Key；未来只有在数据供应方提供明确公开、授权、可商用或获用户授权的接口时，才会新增对应适配器。界面将始终显示实际供应商名称和刷新时间。
