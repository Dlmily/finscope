# 国内市场数据适配评估

## 当前结论

现有移动端只配置了用户设备本地保存的 Finnhub Key，因此默认样例和检索结果偏向其当前可稳定返回报价、K 线、新闻和企业资料的美股标的。不能把未验证覆盖的 A 股代码直接作为可交易默认标的，否则会出现“有名称、无报价或无走势”的误导性界面。

## 可行数据源方向

| 数据源 | 已确认信息 | 适配结论 |
|---|---|---|
| Finnhub | 官方文档提供股票代码、报价、K 线及市场元数据接口；现有 App 已设备本地接入。 | 保留为美股及已验证覆盖市场的可选数据源，不将其表述为 A 股主数据源。 |
| Tushare Pro | 官方数据目录列出沪深、北交所、香港交易所代码后缀，以及 A 股/港股/指数行情类别；文档同时存在权限与频率说明。 | 可作为 A 股、港股和国内指数适配方向，但只能在用户自行取得并导入授权凭证、确认接口权限和传输方式后启用。 |
| 参考小程序内部服务 | 未获得可复用的数据服务契约；此前仅完成有限的正常页面加载观察。 | 不抓取、不逆向、不接入。 |
| Yahoo Finance 公开行情页 | 未登录状态下，`000001.SS` 页面展示延时 CNY 现价、涨跌、涨跌幅和收盘时间；`0700.HK` 页面展示延时 HKD 现价、涨跌、涨跌幅、昨收、今开、日内区间与成交量。离线 `file://` 页面请求其日线端点实测返回 `TypeError: Failed to fetch`。 | 页面可用于字段核查，但不能作为当前 Android WebView 的直连默认数据源；不应以其端点承诺无需账号的可用行情。 |
| 腾讯公开行情与日线端点 | 在离线 `file://` 页面中，`https://qt.gtimg.cn/q=sh600519` 返回 200 格式化行情字符串；`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,day,,,30,qfq` 返回 200 JSON，并得到按日期排列的 OHLCV 日线数组。两者均无需登录或 Token。 | 可作为当前 WebView 内测版本的匿名国内行情候选，适配时需采用 GBK/GB18030 解码行情字符串、标注公开延时数据和供应商时间，并把端点访问失败、延时或字段缺失显示为状态，不承诺实时性或长期稳定性。 |

## 产品调整原则

下一版界面将把市场范围显式分为“沪深京”“港股”“美股”，并将指数、涨跌、行情更新时间和数据源状态放在行情首屏。只有在对应数据源真实返回报价和 K 线后，标的才可进入虚拟买卖；没有覆盖时应显示可理解的未覆盖状态，而不是空白走势图或伪造行情。
